## Правила
- Размеры, кегли, отступы, радиусы, цвета — из макета, не из умолчаний shadcn. Кнопка и поле 48 px, радиус 10, бейдж 24, карточка 12/8.
- Цвета: акцент `#7A2FD1` (ховер `#722BC6`, нажатие `#5B21A8`), бирюзовый `#0E9384` — внутреннее направление. Только токены.
- Шрифты: Onest 400/500/600 и JetBrains Mono. Заголовки — в два тона (`ink` + `ink-3`).
- Состояния: поля и карточки при наведении получают обводку, фон не меняется; кнопки меняют фон. Ховер — по области самого элемента.
- Карточки одинаковой структуры в ряд выравниваются subgrid'ом (как тарифы), чтобы цены и кнопки стояли на одной линии.
- Типограф: короткие слова (1–3 символа) — неразрывный пробел со следующим словом; тире — с предыдущим.
- Сторонние компоненты мимикрируют под систему: карточка системы, Onest, токены.
- Интервалы: 17 → 24, 20 → 27, 40 → 44. Моно — только метки (эйброу, номера, подписи колонок), не основной текст.
- Вложенность не больше двух уровней: серая подложка (поля и зазор 16) → белые карточки → внутри только серые плитки. Без полосок-маркеров у цитат и лишних прогресс-баров.
- Статус = иконка + слово; в таблицах без цветных плашек. Залитая плашка статуса — только вердикт «Проверки обещания».
- Шапки секций — пять вариантов (center, слева, aside, split, faq), чередовать по смыслу. Заголовок вопросов — по краю плашек вопросов.
- Пара карточек разного веса — пропорция макета (1056 : 720), сетка из трёх — равные колонки. Блок с переключением не меняет высоту.
- Графики: поле матрицы квадратное и по центру карточки (симметричные поля сетки); события — пунктир + подпись сверху, как в Nivo.
- Шапка сайта без тени, с обводкой `#e7e6eb`; полоса разделов — только на длинных страницах, прилипает под шапкой.
- Тексты в вёрстке — дословно из макета или `src/content`; ошибки макета не исправляй молча — перечисли.

## Прототип
