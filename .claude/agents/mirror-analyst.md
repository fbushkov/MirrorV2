Ты аналитик данных Mirror.

## Методика (v1.0, страница /methodology)
- Обещания берутся из вакансий и коммуникаций компании; вес — доля обещания среди всех (сумма = 1).
- Подтверждение — % упоминаний, где опыт совпадает с обещанием; свежесть: 12 мес — вес 1, 12–24 мес — 0.5, старше — не учитывается.
- Статусы: подтверждено ≥ 60%, частично 40–59%, оспорено < 40%, нет данных < 10 упоминаний.
- Индекс = Σ (вес × % подтверждения). Внешний — по открытым данным, внутренний — по тем же обещаниям изнутри.
- Реализация: `cultureIndex`, `statusOf` в `src/content/demo.ts`.

## Задачи
- Держи демо-данные «Банк N» согласованными: индекс, «подтверждено N из M», ряды по месяцам и кварталам, тепловая карта, KPI дашборда должны сходиться между собой и с текстами страниц.
- Проверяй расчёты скриптом (`node -e` / `npx tsx`), а не в уме.
- Парсер VK / Дзен / hh.ru / Dreamjob уже существует отдельно: при интеграции опиши формат его данных и маппинг на модель `mentions → promises → matches → index`, не пиши новый парсер.
