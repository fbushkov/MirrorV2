# Журнал решений

Новые записи — сверху. Формат: дата — заголовок · решение · почему · кто решил.

## 2026-10-30 — Новый дизайн в Next один в один
- **Решение:** сайт отдаёт разметку, стили и скрипты прототипа `prototype/home` (выгрузка `build.py --next`, ADR-0008); старые страницы Next на shadcn удалены. Документы и 404 в том же стиле. «О нас» убрана из меню и подвала (`/about` временно на главную), «Заявка» — форма на странице `/start`.
- **Почему:** дизайн согласован в прототипе, старые страницы Next неактуальны; перенос один в один быстрее и без расхождений.
- **Кто:** пользователь.

## 2026-10-30 — «Как считаем» у каждого направления своя
- **Решение:** отдельной общей страницы «Методика» нет. У каждого направления своя «Как считаем»: внутри оценки HR-бренда и внутри дашборда здоровья культуры. В прототипе — `methodology-brand.html` и `methodology-health.html`. В Next при переносе: `/hr-brand/methodology` и `/culture-health/methodology`, со старого `/methodology` — редирект 301 на методику HR-бренда; пункт «Методика» убрать из общего меню и подвала, оставить «Как считаем» в разделах направлений.
- **Почему:** методика описывает конкретное направление; отдельные адреса удобнее людям и поисковикам, чем одна страница с якорями.
- **Кто:** пользователь.

## 2026-10-28 — В git из прототипа только главная и «Цены»
- **Решение:** страница «О нас» удалена из прототипа совсем (ссылки ведут на «#»). Обзор HR-бренда, демо-отчёт, «Как считаем» и демо-дашборд здоровья культуры в git не хранятся (`prototype/home/.gitignore`): пользователь соберёт по ним новый дизайн и пришлёт. Общие стили и иконки для этих страниц остаются в `src/styles.css` и `assets/`.
- **Демо-дашборд:** собран по `/culture-health/demo` из Next (данные `src/content/pulse.ts`): срез с правилом 5 человек, 4 показателя, «Требует внимания» поднят наверх, динамика индекса и двух упавших метрик, 10 метрик со спарклайнами и карточкой, тепловая карта по подразделениям и этапам, разрыв с культурным кодом таблицей, расхождения, лента сигналов, «Снаружи и изнутри».
- **Кто:** пользователь.

## 2026-10-27 — Правила внутренних страниц и таблиц (по правкам страницы «Цены»)
- **Решение:** H1 внутренней страницы = пункт меню, без эйброу, лид свой; шапки секций на внутренних — stack; таблицы — серая подложка, белое тело, «зебра», без линий, без моноширинного шрифта, без плашек и цветных выделений; один стиль значений; короткая таблица без прилипающей шапки; в текстах без стрелок «→» и штампов ИИ; FAQ одним блоком без номера, если группа одна. Правила — `prototype/home/design-system.html`, раздел 13. Применено к «Цены» и «О нас».
- **Почему:** единые стили по главной, без смешения; стандарты UX.
- **Кто:** пользователь (правки), Claude (правила).

## 2026-10-27 — Тестовая страница «Цены», образец отчёта, Роскомнадзор
- **Решение:** страница цен по референсам: тарифы → цена по численности → подробная таблица сравнения → вопросы об оплате (те же, что на главной) и тарифах. Прототип: `prototype/home/pages/pricing.html`. В таблицу добавлены позиции старого сайта (конкуренты, сравнение в динамике, внутренние документы, план от эксперта, сопровождение) и новые (152-ФЗ, группы от 5, данные в РФ). Условные цены и объёмы помечены — ждут подтверждения.
- **Отчёт:** пока используем обезличенный образец; выгрузка парсера — md-файл с теми же данными (ADR-0007).
- **152-ФЗ:** уведомление в Роскомнадзор подано. Почта, SMTP и хостинг у пользователя есть; подключение — позже, пока собираем сайт.
- **Кто:** пользователь.

## 2026-10-27 — Старый репозиторий — действующий сайт; работаем только в MirrorV2
- **Решение:** `fbushkov/mirror.service` — работающий сайт, его код и сервер не трогаем; вся работа только в MirrorV2. Перенос главной из прототипа (`prototype/home`) в Next-приложение пока не нужен — ждём команды пользователя.

## 2026-10-27 — Выгрузка парсера файлом, отчёт формирует ИИ
- **Решение:** парсер отдаёт выгрузку файлом, где всё собрано. Конвейер: выгрузка → проверка схемой → цифры считает код → ИИ формулирует выводы → эксперт проверяет → клиенту PDF. Новый парсер не пишем. Зафиксировано в ADR-0007.
- **Кто:** пользователь.

## 2026-10-27 — Пример отчёта — demo.html старого сайта, дорабатываем во внешнем направлении (ADR-0007, предложено)
- **Решение:** образец — `fbushkov/mirror.service`, `public/demo.html` («Экспресс-аудит HR-бренда», 14 разделов). Структура = три показателя V2 + полезные разделы старого аудита; состав разделов согласовать с пользователем.

## 2026-10-27 — Личный кабинет отложен, к первым продажам достаточно отчёта (ADR-0004 → отложено)

- **Кто:** пользователь.

## 2026-10-27 — Правило переносов: короткие слова не остаются в конце строки

- **Кто:** пользователь.

## 2026-10-24 — Мостик между направлениями (вариант Б)
- **Решение:** показатели направлений не смешиваем и отдельного «индекса изнутри» по обещаниям нет. Индекс культуры считается только по внешним источникам. ## 2026-10-24 — Два направления вместо «контуров» и «Пульса»
- **Решение:** внешнее направление называется «Оценка HR-бренда и индекс культуры» (`/hr-brand`, демо `/hr-brand/demo`); внутреннее — «Дашборд здоровья корпоративной культуры» (`/culture-health`, демо `/culture-health/demo`). Название «Пульс культуры» больше не используем. Слепые зоны и место в отрасли — во внешнем направлении.
- **Сайт:** на главной после первого экрана — посадочный блок «Два направления» (фиолетовая и бирюзовая карточки), затем секция каждого направления. В меню — выпадающий список у каждого направления: обзор, демо, «Как считаем» (`/methodology#brand-method`, `#health-method`). Цены и форма заявки сгруппированы по направлениям. Старые адреса перенаправляются.
- **Цены:** в направление HR-бренда добавлен мониторинг (условно «от 30 000 ₽ в месяц», `<Ph>`); кампания здоровья культуры — прежние 490 000 / 790 000 / 1 290 000 ₽.
- **Почему:** пользователь попросил явно разделить две смысловые части.
- **Кто:** пользователь (названия), Claude (структура и цена мониторинга).

## 2026-10-24 — Пульс культуры: внутренний контур по ТЗ (название заменено, см. выше)
- **Решение:** внутренняя сторона Mirror = продукт «Пульс культуры» (название оставляем): индекс переживаемой культуры, разрыв с культурным кодом — главный показатель, 10 метрик в трёх группах, приватность (группы от 5 человек). Новая страница `/pulse`, демо-дашборд кликабельный (`/example/pulse`). Слепые зоны и место в отрасли не менять.
- **HR-сигналы** (текучесть новичков, отказы от офферов) — только в методике как подтверждающие сигналы, не в продающих текстах.
- **Цены:** «Сопровождение» влито в Пульс; Пульс — разовая кампания на 3 месяца: 490 000 / 790 000 / 1 290 000 ₽ (до 300 / 300–1000 / 1000–3000 сотрудников). Цены определил Claude по рынку по поручению пользователя.
- **Кто:** пользователь.

## 2026-10-24 — Три показателя вместо одного
- **Решение:** индекс культуры остаётся мерой соответствия собственным обещаниям. Рядом два отдельных показателя: «слепые зоны» (о чём люди говорят, а компания молчит) и «место в отрасли» (условия против рынка, перцентиль). В одну цифру не смешиваются. Матрица «честность × условия» с четырьмя зонами.
- **Почему:** индекс от своих обещаний выгоден при молчании и не показывает привлекательность условий.
- **Кто:** пользователь (по рекомендации).
- **Методика:** документы компании — источник обещаний, подтверждение изнутри — интервью, опросы, фактические данные.
