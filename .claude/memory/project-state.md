# Состояние проекта Mirror V2

_Обновлено: 2026-10-24. Ведёт агент `mirror-context-keeper`._

## Цель
Новая версия сайта Mirror (mirror-com.ru) под новое позиционирование: бесплатный внешний срез → платная диагностика внешнего и внутреннего бренда с экспертом.

## Сделано
- Тексты старого сайта собраны: `docs/content/site-texts.md`, юр. документы — `docs/content/legal/`.
- Тестовый сайт на Next.js 16 + Tailwind 4 + shadcn/ui + ECharts 6 (ветка `claude/practical-gates-pzc7nm`):
  первая версия (19 страниц, тёмная тема) заменена структурой v2.
- Тексты перенесены со старого сайта и прототипа v4; темы подбора и текучести убраны.
- **Сайт пересобран по структуре v2** (`docs/ux/site-structure.md`): светлая тема, фиолетовый акцент `#A847B8`, без старого логотипа и картинок.
  Страницы: `/`, `/hr-brand`, `/hr-brand/demo`, `/culture-health`, `/culture-health/demo`, `/methodology`, `/pricing`, `/about`, `/start`, `/docs/*`.
  Главная: зеркало → разрыв → две стороны → три показателя → 4 шага → ситуации → данные → цены → вопросы → форма.
- Три показателя (индекс культуры, слепые зоны, место в отрасли) и матрица «честность × условия»: главная, `/hr-brand`, `/methodology`, `/hr-brand/demo`.
- Дашборд здоровья культуры по ТЗ: `/culture-health` (15 блоков, якорное меню), демо `/culture-health/demo` (фильтры, правило 5 человек, карточки метрик), данные `src/content/pulse.ts`.
- **Разделение на два направления** (решение пользователя): «Оценка HR-бренда и индекс культуры» — `/hr-brand` и `/hr-brand/demo`;
  «Дашборд здоровья корпоративной культуры» — `/culture-health` и `/culture-health/demo`; общая `/methodology`. Главная: первый экран →
  разрыв → «Два направления» → секция каждого → «Вместе» → шаги → … Меню с выпадающими списками по направлениям. Цены и форма — по направлениям.
  Редиректы со старых `/pulse`, `/example`, `/example/pulse`, `/culture-index`. Цвет внутреннего направления — токены `health-*` (бирюзовый).
- Превью опубликовано артефактом: https://claude.ai/artifact/KMyqLFdyA8zBzkdZqgU7sf (сборка в `.preview/`, не в git).
- Архитектура агентов продукта (на будущее): `docs/architecture/agents.md`.
- Агенты разработки, память и логирование Claude Code: `.claude/agents/`, `.claude/memory/`, `.claude/hooks/`, `CLAUDE.md`.
