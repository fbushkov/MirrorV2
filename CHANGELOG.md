# История изменений Mirror V2

Ведёт агент `mirror-release`. Новое — сверху, в разделе «Не выпущено». Группы: Добавлено · Изменено · Исправлено · Удалено.
Продуктовые решения — `.claude/memory/decisions.md`, архитектурные — `docs/adr/`.

## Не выпущено

### Добавлено
- Проверка символов и текстов `npm run check:text` (`scripts/check-text.mjs`): невидимые символы, эмодзи, NBSP символом в коде, «→», штампы, дефис вместо тире, запрещённые темы. Входит в `npm run check` и CI.
- Архитектура сайта и платформы: `docs/architecture/site.md` — этапы (сайт → заявки → админка → кабинет), зоны маршрутов, слои кода, данные, доступы.
- Журнал архитектурных решений `docs/adr/`: многостраничность, источник дизайна, заявки, доступы, тесты.
- Тесты: Vitest для чистых функций, Playwright-смоук по всем страницам на десктопе и телефоне; CI в GitHub Actions.
- Карта страниц `ROUTES` в `src/content/site.ts`; из неё — `sitemap.xml`, `robots.txt` и смоук-тесты.
- Типограф `src/lib/typograf.ts`: короткие слова не остаются в конце строки.
- Агенты разработки: архитектор, дизайн-система, тесты, ревьюер, история изменений, кабинет и админка, SEO.
- HTML-прототип главной и «О нас» по макету Figma с дизайн-системой (`prototype/home`).
- `.env.example` с переменными будущих этапов.

### Изменено
- Прототип очищен: комментарии без рамок и капса, удалены 40 неиспользуемых классов в `styles.css` (1217 → 1137 строк), 7 неиспользуемых картинок; скриншоты `qa.js` больше не хранятся в git. Вид страниц не изменился (сверка 36 снимков).
- Сайт на Next: убраны стрелки «→» из текстов и подписей графиков, упоминание текучести на «Методике»; NBSP в типографе записан как `\u00a0`.
- «Вы сказали — мы сделали» переименовано в «Решения по обратной связи».

## 2026-10-24 — первая версия сайта V2
- Сайт на Next.js 16, Tailwind 4, shadcn/ui и ECharts 6, светлая тема, структура v2.
- Два направления: «Оценка HR-бренда и индекс культуры» (`/hr-brand`, демо) и «Дашборд здоровья корпоративной культуры» (`/culture-health`, демо); методика, цены, о нас, заявка, документы.
- Три показателя внешнего направления (индекс культуры, слепые зоны, место в отрасли) и матрица «честность × условия».
- Мостик между направлениями без общего индекса; единая демо-компания «Банк N».
- Тексты старого сайта и юридические документы перенесены в `docs/content`.
- Агенты разработки, память проекта и логирование в `.claude/`.
