# 0007. Отчёт внешнего анализа: выгрузка парсера → ИИ → PDF
- Статус: предложено · Дата: 2026-10-27 · Кто: пользователь (отчёт вместо кабинета, данные — файлом), Claude (схема)

## Контекст
Клиенту на старте достаточно отчёта, кабинет не нужен (ADR-0004 отложен). Пример отчёта есть на старом сайте:
`fbushkov/mirror.service` → `public/demo.html`, «Экспресс-аудит HR-бренда», 14 разделов (резюме, метод и охват, позиционирование,
восприятие, карта подтверждений EVP, вакансии hh.ru, соцсети, персоны, конкуренты, контент-стратегия, SWOT, план, метрики, приложения).
Его нужно доработать и разместить во внешнем (фиолетовом) направлении. Парсер отдаёт выгрузку файлом, где всё собрано.

## Решение (предложено)
- **На сайте:** доработанный демо-отчёт — в направлении «Оценка HR-бренда» (`/hr-brand/demo` или `/hr-brand/report`), в дизайне по макету,
  на демо-компании «Банк N». Реальную компанию из старого примера не показываем.
- **Структура отчёта** = три показателя V2 (индекс культуры, слепые зоны, место в отрасли, матрица) + полезные разделы старого аудита.
  Состав согласовать с пользователем (`mirror-content`, `mirror-analyst`).
- **Конвейер:** выгрузка парсера (файл) → проверка схемой → расчёт показателей (код, не ИИ) → ИИ пишет текстовые выводы →
  эксперт проверяет → PDF клиенту по почте. Цифры считает код, ИИ только формулирует.
- Один шаблон отчёта для сайта и PDF (печатная версия страницы).

## Открыто
Образец выгрузки парсера; где выполняется генерация (локально у эксперта или на сервере); утверждение состава разделов.
