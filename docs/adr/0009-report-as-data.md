# 0009. Отчёт хранится как данные по одной схеме
- Статус: принято · Дата: 2026-11-01 · Кто: пользователь (кабинет проектировать заранее, хранить результаты так, чтобы кабинет открылся с историей), Claude (схема)

## Контекст
Сейчас клиент получает PDF (ADR-0007), кабинет появится с первым договором на кампанию. Если хранить только PDF,
при запуске кабинета старые отчёты придётся разбирать обратно в цифры, а цифры в PDF и кабинете могут разойтись.
Методика уже описана на сайте и проверяема: пороги статусов, веса, зоны, правило 5 человек.

## Решение
- Любой отчёт (срез, мониторинг, диагностика, замер, итог кампании) — один JSON по схеме `src/lib/schemas/report.ts`.
  Из него собираются PDF, PDF под брендом агентства и кабинет.
- Направления — отдельные блоки `external` и `internal` со своими шкалами, связь только по темам (`bridge`). Общей цифры нет.
- Пороги методики — в коде (`src/lib/report/methodology.ts`); схема проверяет согласованность чисел при разборе.
- Персональных данных в отчёте нет; изнутри только агрегаты групп от 5 человек и проверенные цитаты без подразделения.
- Хранение: неизменяемые версии в `report_versions` (jsonb, `schemaVersion`, хэш), PDF — файлом рядом. Исходные данные
  (выгрузка парсера, сырые ответы изнутри) — отдельно, со ссылкой из версии. Подробно — `docs/product/report-data.md`.
- Зависимость `zod` 4 добавлена (схемы Zod в `src/lib/schemas` уже были в архитектуре, `docs/architecture/site.md`).

## Последствия
- Кабинет откроется с историей всех отчётов клиента.
- ИИ получает схему (JSON Schema) и заполняет только текстовые поля; ошибку в цифрах ловит проверка.
- Новые поля добавляются в схему с тестом; несовместимое изменение — новая `schemaVersion` и миграция.
- Демо-отчёт «Банка N» проверяется той же схемой, поэтому демо на сайте и методика не расходятся.
  Первая находка: на карте «честность и условия» у «Банка N» были перепутаны оси, исправлено в прототипе.

## Альтернативы
- Хранить только PDF: проще сейчас, но история для кабинета теряется.
- Отдельные таблицы под каждый показатель сразу: преждевременно, пока отчётов мало и схема будет меняться.
