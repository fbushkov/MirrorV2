# 0006. Хостинг — REG.RU, сервер ведёт пользователь
- Статус: принято · Дата: 2026-10-27 · Кто: пользователь

## Решение
- Сайт размещается в REG.RU, сервер администрирует пользователь сам. Данные в РФ (152-ФЗ).
- Поставка — docker compose: Next.js `output: "standalone"`, Postgres (с этапа заявок), nginx с HTTPS (Let's Encrypt).
- `mirror-devops` готовит Dockerfile, compose, конфиг nginx и инструкцию: установка, обновление, откат, бэкап Postgres (зашифрованный, в РФ).
- Старый сайт (`fbushkov/mirror.service`) продолжает работать как есть; V2 не трогает его ни кодом, ни сервером.

## Открыто
Тариф (VPS/облачный сервер), ОС, домен для V2 до переключения основного.
