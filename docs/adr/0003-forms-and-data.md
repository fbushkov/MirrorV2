# 0003. Заявки: Server Action → Postgres → outbox → уведомления
- Статус: принято частично · Дата: 2026-10-27 · Кто: пользователь (канал — почта, хостинг REG.RU), Claude (схема); ORM — открыто

## Контекст
Форма на главной и `/start` пока ничего не отправляет. Заявка не должна теряться, даже если почта или Telegram недоступны.
Персональные данные — по 152-ФЗ, хранение в РФ.

## Решение (предложено)
- Server Action с общей Zod-схемой (`src/lib/schemas/lead.ts`), антиспам (ловушка, время заполнения, лимит по IP).
- Postgres: `leads`, `consents` (версия согласия, время, хэш IP), `outbox`. Уведомления — воркер по outbox с повторами.
- ORM — Drizzle (схема на TS, SQL-миграции в git, лёгкий рантайм). Альтернатива — Prisma.
- Канал — **только почта** (решение пользователя 2026-10-27): письмо команде через SMTP почты на домене (сервер в РФ).
  Telegram и CRM — позже, адаптерами к outbox, без изменения формы.

## 152-ФЗ — обязательно до запуска формы
- Уведомление Роскомнадзора об обработке ПДн (ст. 22).
- Согласие — отдельный документ, чекбокс не отмечен заранее. В `consents`: версия и хэш текста, цель, состав полей, время, хэш IP, дата отзыва.
- Сроки хранения заявок, удаление, отзыв согласия, ответ на запрос субъекта за 10 рабочих дней (ст. 14, 21).
- Уведомления в Telegram и зарубежную почту — трансграничная передача (ст. 12). Поэтому в уведомление идёт только
  «новая заявка #id, тема» со ссылкой в админку, без ФИО и контактов; почта команды — в РФ.
- Данные хранятся и бэкапятся в РФ, бэкапы зашифрованы.
- Дашборд здоровья культуры: Mirror обрабатывает ПДн сотрудников клиента по поручению (ст. 6 ч. 3) — нужен договор-поручение и порядок удаления после проекта.
- Данные парсера: авторы отзывов — ПДн (ст. 10.1); имена не храним, если не нужны.

## Технические требования
- Server Actions за обратным прокси: `serverActions.allowedOrigins`, `bodySizeLimit`.
- Лимит частоты — в Postgres/Redis (не в памяти процесса), по IP и по контакту.
- Длины полей ограничены в Zod; в письмах экранируем HTML, в Telegram шлём без разметки.
- ПДн маскируются в общем логгере; тела запросов не логируются.
- Яндекс Метрика — только после согласия на cookies, без Вебвизора на формах, ПДн не в целях и параметрах.

## Нужно от пользователя
Адрес для заявок и SMTP-доступ (почта на домене в REG.RU или другой российский сервис), уведомление Роскомнадзора, срок хранения заявок.
