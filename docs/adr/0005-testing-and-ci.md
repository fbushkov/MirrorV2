# 0005. Тесты и CI
- Статус: принято · Дата: 2026-10-27 · Кто: пользователь (контроль тестов), Claude (инструменты)

## Решение
- **Vitest** — модульные тесты чистых функций: `src/**/*.test.ts` (`npm test`).
- **Playwright** (`@playwright/test`) — e2e по собранному сайту: `tests/e2e/*.spec.ts` (`npm run test:e2e`).
  Базовый смоук: все маршруты из `ROUTES` отвечают 200, без ошибок консоли и без горизонтальной прокрутки на 390 px.
- **CI** — `.github/workflows/ci.yml`: lint → tsc → unit → build → e2e на push и PR.
- Тесты пишет `mirror-tests`, прогоняет и проверяет визуально `mirror-qa`, ревью диффа — `mirror-reviewer`.
- Тест нельзя отключать или пропускать, чтобы получить зелёный CI.
