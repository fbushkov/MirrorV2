# Бэклог Mirror

Открытые вопросы и отложенные задачи в одном месте, чтобы к ним вернуться. Обновлено 2026-11-01.
Вопрос закрыт — переносим решение в профильный документ и журнал (`.claude/memory/decisions.md`), строку здесь удаляем.

Кто решает: **В** — владелец сервиса, **Э** — эксперт, **Ю** — юрист, **Р** — разработка.
Когда нужно: к какому этапу без ответа не обойтись.
